# 타로 카드 이미지 자료

## 출처

- 아카이브: https://cha-amu.github.io/archive/
- 원본 manifest: https://cha-amu.github.io/storage/manifests/assets.json
- 내려받은 날짜: 2026-07-16

모든 카드 이미지는 사용자가 직접 제작한 작업물이며, 사용자가 이 프로젝트에서의 사용을 확정했다. 이 프로젝트에서 사용하는 데 별도의 외부 라이선스 제약은 없다.

## 포함된 파일

- `source/`: 원본 PNG 이미지 79장
- `manifest.json`: 제목, 태그, 원본 URL, 로컬 경로가 포함된 이미지 목록
- `SHA256SUMS.txt`: 내려받은 파일의 SHA-256 체크섬

표준 타로 카드 78장은 모두 `512×768`이고, 추가 테마 카드 `밀크티` 1장은 `512×512`이다. 앱의 기본 덱은 메이저 22장과 마이너 56장으로 구성된 표준 78장 전체를 사용한다. `밀크티`는 기본 덱에 포함하지 않고 별도 원본 자료로 보관한다.

## 사용 규칙

- 앱 코드에서 긴 원본 파일명을 직접 작성하지 말고 `manifest.json`을 통해 경로를 연결한다.
- 원본 이미지는 `source/`에서 직접 수정하지 않는다.
- 크기 변경이나 포맷 변환이 필요하면 별도의 파생 이미지 폴더를 만든다.
